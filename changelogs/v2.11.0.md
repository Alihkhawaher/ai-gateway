# v2.11.0 — 2026-11-11

## Added
- **Tool calls a model wrote straight after `</think>` are healed.** A Gemma 4 finetune on LM Studio sometimes closes its thinking with `</think>`, which isn't that format's closing tag. LM Studio then treats the tool call that follows as more thinking: the reply has no answer and no call, and the agent stops. With `tool_heal` on, the gateway now sends those calls as real tool calls:
  - Only when the reply ended normally with no answer text and no call, and everything after `</think>` is complete calls in Gemma 4's format (`<|tool_call>call:name{…}<tool_call|>`).
  - A call the model only thought about (no `</think>` before it, words after it, or cut off) is left as it came, byte for byte.
  - The command guard checks these calls like any other, and values are passed on as the model wrote them.
