# v2.4.0 — 2026-08-30

## Added
- **MCP "Use llama-server proxy" support** — the web UI's MCP server toggle now works:
  - `GET /props` advertises `cors_proxy_enabled: true`, enabling the toggle in the bundled llama-ui (the same signal llama-server emits via `--ui-mcp-proxy`).
  - `/cors-proxy` now forwards the MCP **session handshake** correctly:
    - Normal request headers and `x-llama-server-proxy-header-*` prefixed headers are forwarded upstream, with prefixed headers taking precedence (so the correct `Content-Type: application/json` wins over a browser auto-added `text/plain`).
    - Upstream response headers (notably `Mcp-Session-Id`) are forwarded back to the browser, enabling stateful MCP bridges (e.g. `supergateway`) to complete their session handshake.
- **Automated test suite** in `testing/test_proxy.py` (`unittest`, no third-party runner) — 12 tests covering `/props`, `/cors-proxy` forwarding, header precedence, session round-trip, and error handling.
- **Web UI updated to the latest llama.cpp llama-ui** (rebuilt from current `llama.cpp` source).

## Changed
- `.gitignore`: the `testing/` directory is now tracked (only `testing/__pycache__/` is ignored).

## Docs
- `claude.md`: documented MCP support, added a **Testing Convention** (every feature/bug fix must include a test procedure), and noted the `testing/` layout.
- `README.md`: added MCP and testing sections.
