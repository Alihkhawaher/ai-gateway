# v2.6.0 — 2026-11-05

## Added
- **KV session swap (`kv_sessions`, per endpoint, off by default).** A local engine like Strata holds one conversation; switching between apps that each keep a long chat used to mean reading the other chat again from scratch (15+ minutes at 500k tokens). The gateway now saves the held chat to disk and restores the right one before forwarding each request, so a switch takes seconds:
  - **Conversations are recognised by message hashes**, with no id needed from the app. A request that continues the held chat touches nothing; one that moves away saves the held chat if it is long and has changed, then restores the saved chat that matches best.
  - **One request at a time per managed endpoint**, in the same order the engine would have queued them.
  - **Idle save** (`idle_save_s`, default 10 minutes), so unloading the model loses little.
  - **Optional disk limit** (`max_gb`, default off): deletes the oldest of its own session files only.
  - **Strata needs no extra setup in the gateway**: it finds the engine's port and key in Strata's own run files for each load. The key stays in memory and is never logged or copied.
  - Session files are never opened by the gateway, and its index holds only hashes and counts, never chat text.
  - `GET /health` reports the sessions, the held chat and the save/restore counts.
- **`testing/live_kv_check.py`**: checks the swap against a real engine with made-up text.

## Fixed
- Editing an endpoint in the TUI no longer drops settings the dialog doesn't show (`timeout`, `kv_sessions`).
