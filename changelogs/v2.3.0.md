# v2.3.0 — 2026-08-21

## Added
- **`config.example.json`** — Committed configuration template with placeholder API keys so a fresh clone has a clear starting point (the real `config.json` remains gitignored).
- **Functional endpoint management TUI** — The settings screen now has working `+ Add`, `✎ Edit`, and `✕ Remove` buttons wired to the previously-unused `EndpointEditScreen`, with duplicate-name validation and persistence to `config.json`.
- **`/cors-proxy` endpoint** — llama.cpp/llama-ui compatible CORS proxy (`GET/POST /cors-proxy?url=<target>`), forwarding `x-llama-server-proxy-header-*` request headers (prefix stripped) and returning permissive CORS headers. Restores the web UI's external-fetch capability.
- **`/models/load` behavior** — Model loads now validate the request and set the model as the new default (`model_index`, persisted to disk), returning success/error JSON instead of a silent no-op.

## Changed
- **Model catalog caching** — OpenRouter/OrcaRouter catalogs are now cached for 5 minutes instead of being re-downloaded on every 30-second health-check cycle.
- **Smarter request routing** — Requests naming a disabled/offline source prefix now return a clear `404`/`503` error instead of silently falling back to the first enabled endpoint.
- **Thread-safe `MODELS` list** — Added a dedicated lock with `get_models()`/`set_models()` accessors used across config loading, aggregation, top-model fetching, and HTTP handlers.
- **Restart safety** — The TUI server-restart path now catches bind errors and logs them instead of terminating the whole process via `sys.exit(1)`.
- **`build-webui.cmd` guard** — Fails with clear instructions if the gitignored `webui-src/` source (a llama.cpp clone) is missing.
- **README** — Quick Start references `config.example.json`, and the web UI build section documents the `webui-src` clone prerequisite.

## Fixed
- Removed silent endpoint fallback that could forward a request (with the wrong API key) to an unintended backend.
- Eliminated redundant full-catalog downloads every health-check cycle.
