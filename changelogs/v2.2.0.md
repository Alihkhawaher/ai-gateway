# v2.2.0 — 2026-08-21

## Added
- **OrcaRouter provider** — New cloud endpoint type for OrcaRouter (`api.orcarouter.ai`), an OpenAI-compatible multi-provider gateway that routes requests across OpenAI, Anthropic, Google Gemini, DeepSeek, xAI Grok, Alibaba Qwen, Moonshot Kimi, MiniMax, and more at provider cost price
- **OrcaRouter health checking** — HTTPS health check via `GET /api/v1/models` (same protocol as OpenRouter)
- **OrcaRouter model fetching** — `fetch_orcarouter_models()` function retrieves the full model catalog for metadata enrichment
- **OrcaRouter path rewriting** — Requests to OrcaRouter use `/api/v1` prefix rewriting, matching OpenRouter's API structure
- **OrcaRouter in TUI** — "OrcaRouter" option in the endpoint type dropdown with auto-filled defaults (`api.orcarouter.ai`)
- **OrcaRouter in README** — Full documentation including configuration example, model ID format, endpoint type table, and tested backends

- **Model list updates** — Added new models across both providers: DeepSeek V4 Pro, GLM 5.3, Claude Sonnet 5, Qwen 3.8 27B, Kimi K3
- **Uncensored model** — Added `obsidian/Qwen3.6-35B-A3B` (uncensored Qwen) via OrcaRouter
- **Removed outdated models** — Removed `qwen/qwen3.7-plus`, `qwen/qwen3.7-flash`, `z-ai/glm-5.2` (OpenRouter), `deepseek/deepseek-chat` (OrcaRouter)

## Notes
- OrcaRouter does not provide a programmatic top-model sorting API (unlike OpenRouter's `?sort=intelligence-high-to-low`). The `fetch_top_models` feature remains OpenRouter-only.
- OrcaRouter uses `/v1/models` (not `/api/v1/models` like OpenRouter). The host `api.orcarouter.ai` already includes the `api.` prefix.
- OrcaRouter model IDs use `vendor/model` format (e.g., `openai/gpt-4o-mini`, `anthropic/claude-sonnet-4.6`). Model IDs in the gateway follow the `orcarouter/vendor/model` pattern.
- OrcaRouter API keys start with `sk-orca-`.
