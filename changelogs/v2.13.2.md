# v2.13.2 — 2026-11-12

## Fixed
- **The gateway reported 128,000 for a model with a larger context window whenever Strata was busy.** When Strata's model details couldn't be read, or the model wasn't marked ready at that moment, the gateway fell back to a default of 128,000 and told apps that. Apps then showed and used 128k, and the context guard said "full" far too early (at 156k of a 262k window). A model now keeps the last window its endpoint reported. Only a window that was never reported gets the default, and the guard and the stats never act on that guess. LM Studio, llama.cpp and Ollama endpoints follow the same rule.
- **The context guard's summary re-read the whole chat.** The summary request added a "no tools" setting and left out the request's other parameters, so the engine built a different prompt and read all of it again. The request now goes out exactly as the app's own request did, so the engine reads it from its cache.
