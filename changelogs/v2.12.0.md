# v2.12.0 — 2026-11-11

## Added
- **A full context reaches the app as the standard error.** When an engine says the prompt doesn't fit, the gateway now answers `400` with the OpenAI code `context_length_exceeded`, the token counts where the engine gave them, and the engine's own words. Apps with overflow recovery, such as Cline, compact and retry on it. Before, each engine's own wording passed through (llama.cpp: "exceeds the available context size"), which such apps read as a plain failure, and the run stopped. `/v1/messages` gets Anthropic's form. Every other error still passes byte for byte.
- **The console shows a chat nearing the limit.** From 90% of the context window, Recent requests shows the share used beside the prompt size, and the log line says `context 92% full`. A request that hit the limit shows `ctx full`. `GET /stats` has `overflow`, `window` and `window_used` on each recent request.

## Fixed
- **Apps were told the wrong context window for LM Studio models.** `/v1/models` and `/props` reported the model's maximum, such as 262,144, even when it was loaded with 32,000, so an app would compact far too late. They now report the loaded window, with the maximum in `max_context_length`.
