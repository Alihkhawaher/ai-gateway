# v2.13.1 — 2026-11-12

## Fixed
- **Asking the gateway about one model returned an error.** `GET /v1/models/<id>` and `GET /api/v0/models/<id>` were forwarded to an engine and came back as a 502. An app that looks its model up this way to learn the context window then fell back to its own default, which is 128,000 in Cline and Goose. The gateway now answers these itself, by its own id (`strata:model`) or the engine's, with the same context window as the lists.

## Added
- **Ollama-style model info:** `GET /api/tags`, `GET /api/ps` and `POST /api/show` report the models and each one's context window, for apps that ask an Ollama server.
- **The log shows which model lookups each app makes** (`model lookup: GET /v1/models/<model>`, once per kind every ten minutes), so it's clear where an app gets a model's context window from, or that it never asks.
