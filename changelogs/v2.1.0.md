# v2.1.0 — 2026-08-21

## Added
- **LM Studio-compatible API endpoint** — New `/api/v0/models` and `/api/v1/models` endpoints that return models in LM Studio format, enabling Cline's LM Studio provider to auto-discover models from the gateway
- **Cline integration via LM Studio provider** — Select "LM Studio" in Cline, set base URL to `http://YOUR_IP:8090`, and the model dropdown populates automatically
- **TUI footer key bindings** — Settings (`s`), Quit (`q`), Save (`Ctrl+S`), Restart (`Ctrl+R`), Back (`Esc`) now appear as clickable items in the built-in Footer bar
- **Server info display** — Main screen shows Listening URL, Web UI URL, and Default model after the endpoints section

## Changed
- **TUI main screen layout** — Uses `ScrollableContainer` with consistent `section-title` styling matching the settings screen
- **TUI settings screen** — Removed non-working Add/Edit/Remove endpoint buttons; endpoints table is now read-only status display
- **Server info display** — Shows `localhost` instead of `0.0.0.0` for better readability
- **Top intelligent models** — Now persist across health check cycles (included in OpenRouter metadata fetch)
- **SSL context** — Reuses shared `_upstream_ssl_ctx` instead of creating new contexts per request

## Fixed
- **Top models disappearing** — Models fetched via `fetch_top_models` were dropped after the first health check cycle because `aggregate_models()` only included user-configured models in the OpenRouter fetch
- **Unused CSS** — Removed `#main-toolbar` and `#ep-buttons` CSS rules for removed elements
- **Unused variable** — Removed `user_model_set` in `aggregate_models()`
