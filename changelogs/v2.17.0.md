# v2.17.0 — 2026-11-19

## Added
- **Live engine numbers for llama-server endpoints.** The console's Live panel and `GET /stats` now show a `llama-server` endpoint's own state, as they already did for Strata:
  - reading the prompt, with progress and time left;
  - generating, with live tokens per second and a 60-second sparkline;
  - idle.
  - They also show the context size, requests waiting, the share of prompt tokens reused from cache, draft acceptance (MTP, n-gram or draft model) and prompt-reading speed.
  - The gateway reads `/slots` and the Prometheus `/metrics` page. Start llama-server with `--metrics` for the totals; without it, the live slot still shows.
  - Only named counters are read, and they go through the same allow-list as Strata's numbers, so no prompt or reply text reaches the console or `/stats`.
  - Polling runs every 2 seconds, and only while someone is looking.

## Changed
- **The console features the engine that's serving.** With several engines online, the Live panel shows the one with a request in flight, then the one that served the latest request. It no longer always shows the first one configured.

## Tests
- 10 new tests (`LlamaServerProbeTests`) against a mock llama-server:
  - field mapping;
  - live speed from one poll to the next, with no carry-over to a new request;
  - prompt progress, idle and missing `--metrics`;
  - odd `/slots` shapes;
  - a dead server;
  - no text in the view;
  - which engine the console features.
