# v2.14.0 — 2026-11-12

## Added
- **A call the model keeps repeating is stopped before the app ends the task.** A stuck model makes the same call again and again, and some apps then stop the whole task (Cline 4.1.26: "Detected 5 consecutive identical calls"). With `"stop_repeats": true` inside an endpoint's `tool_heal`, or **Stop a call the model keeps repeating** in the endpoint's dialog, the gateway lets the same call run three times in a row and replaces the fourth with a call to a tool named `gateway_stopped_R1_same_call_repeated_in_a_row_use_its_result_or_change_the_call`. The app answers that the tool doesn't exist, the model reads the name, and the task carries on. Off by default.
  - The same call means the same tool and the same arguments. JSON spacing and key order don't matter; any other difference makes it a different call.
  - The count comes from the request's own messages, so nothing is kept between turns. A message from the user, an answer in words or another call starts it again.
  - The model is told once. The same call made again after that runs, so a call that really must repeat is never locked out.
  - One reply that makes the same call more than three times is stopped as a whole (rule R2).
  - The user is never asked, so an unattended run goes on.
  - `repeat_limit` (2 to 20, default 3) sets how many identical calls in a row may run.
- The Settings table's **Heal** column shows `↻` when the stop is on.

## Changed
- README, `claude.md` and `config.example.json` brought up to date: model ids are written `source:model`, the per-endpoint options are in one table, and the API table lists every endpoint the gateway answers.
