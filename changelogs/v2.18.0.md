# v2.18.0 — 2026-11-19

## Added
- **Tool calls that can't run anything stream as they're written.** With tool healing on, the gateway used to hold every structured tool call until the reply ended, so the web UI showed only "processing" and then the whole call at once. Now a call to a declared tool streams live when the tool can't run or write anything:
  - The tool isn't a command or editing tool.
  - Every parameter is a plain value (text, number, yes/no, a choice or a list of those).
  - No parameter is named for a command, a path, code or free-form arguments.
  - Search, fetch and read-style MCP tools usually qualify.
  - Commands, file writes, tools with object parameters and undeclared names are still held and checked as before, and so is every call after a held one.
  - Nothing streams live while a repeat stop could apply.
- **Live numbers for a request in flight.** The Live panel's **In flight** line now lists up to three running requests: app, endpoint, phase (waiting, reading, thinking, writing or tool call), tokens so far, tokens per second and time.
  - It works for every endpoint, LM Studio included.
  - A tool call the gateway is holding is counted while it's written.
  - `GET /stats` carries the same fields (`active[].phase`, `out`, `tok_s`, `ttft_s`, `calls`). Counts only.

## Fixed
- **Strata swaps no longer restore a chat saved under another model.** Strata refuses such a file ("saved with another model (model fingerprint differs)"), and the gateway used to try it again on every switch.
  - Each saved chat now records its model, and only chats from the same model are restored.
  - A file the engine refuses isn't asked for again while that model stays loaded.
  - A fingerprint refusal marks the file stale, so it's never tried again and is the first deleted when the sessions folder is over `max_gb`.
  - Chats saved before this version may try once, and are tagged when they restore.
