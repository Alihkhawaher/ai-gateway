# v2.18.2 — 2026-11-19

## Changed
- **A stopped tool call now tells the model what happened.** When the guard stops a call and the app offers no `ask_question`, the model gets a call to a made-up tool such as `gateway_stopped_T1_reply_was_cut_off_send_a_shorter_call`, which the app answers with "unavailable tool". Its arguments used to be `{}`. They now carry a `note` the model reads back:
  - which tool's call was stopped;
  - why, and that nothing ran;
  - what to send instead.
  - **T1 (cut off):** the note gives the request's own output limit (for example 4,096 tokens), says to send the change in smaller pieces, and, when the limit is under 16,384, what to tell the user: raise max output tokens to 32768 or more in the app's model settings and restart the app. Cline's OpenAI Compatible provider defaults to 4,096, which cuts off long file writes.
  - **A1:** send valid JSON (backslashes in Windows paths doubled).
  - **R1 / R2:** how many times the call was repeated, and to use the result already there.
  - The note has tool names and counts only, never the command.

## Tests
- Two new: the T1 note with a 4,096 limit (the numbers and the advice, no command text), and with a large limit (no settings advice).
- Two updated: the unknown-tool stop now checks the note, and the repeat stop checks it while confirming the call itself never goes out.
