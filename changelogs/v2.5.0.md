# v2.5.0 — 2026-09-02

## Added
- **`gateway_tui.py` — split-view TUI** that runs the AI Gateway proxy and Supergateway together in a single terminal:
  - **Top pane: the full proxy GUI** — endpoint status (online/offline indicators), server info, live proxy log, and Settings (`s`) — reused by subclassing `proxy.py`'s `MainScreen`/`ProxyTUI` classes. `proxy.py` itself is not modified.
  - **Bottom pane: Supergateway** — live output of the streamable HTTP MCP server on `:8099`, with the filesystem server root `./supergateway` kept **relative** (resolved against the project directory, no hardcoded absolute paths).
  - Windows-compatible `npx` launch (`shell=True` + `list2cmdline` quoting), full process-tree cleanup on quit (`taskkill /T`), and graceful proxy server shutdown.
  - Quit with `q` stops Supergateway and shuts down the proxy cleanly.

## Changed
- **`run.cmd` now launches `gateway_tui.py`** (the split-view TUI) instead of `proxy.py` alone, with an updated startup banner showing both services.
