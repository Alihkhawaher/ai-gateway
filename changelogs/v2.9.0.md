# v2.9.0 — 2026-11-10

## Added
- **How each reply ended, in the console and the log.** When an agent stops on its own, the model's last reply usually shows why. The **Recent requests** panel has a new **End** column, and each log line says `ended: …`:
  - `N calls`: the reply made tool calls.
  - `no call`: tools were offered, but the reply was text only. An agent takes that as the end of its turn.
  - `cut off`: the reply hit the token limit.
  - `ctx full`: the context window filled up.
  - `no end`: the stream ended without a reason.
  - `empty`: no answer text.
- This works for the OpenAI, Anthropic, Responses API and Ollama formats. The gateway reads it from the model's own stream, before any healing. Only a finish reason from a fixed list, a tool-call count and character counts are kept, never the text. `GET /stats` has them as `finish`, `calls`, `tools`, `text_chars` and `reasoning_chars` on each recent request.
